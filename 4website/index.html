About the Game

New Super Mario Bros. Wii is a platform game developed and published by Nintendo for the Wii console. It features classic side-scrolling gameplay and up to four-player multiplayer.

Main Features

  • 4 Player Co-Op
  • Classic Side-Scrolling Gameplay
